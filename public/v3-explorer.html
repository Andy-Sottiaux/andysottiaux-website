02How It Boots

Click any stage to expand. Total power-on to fully-operational: ~75 seconds.

t=0sBoot ROM
RV1106's mask ROM reads idblock (256 KB at offset 32K+512K) and loads it. This is the rockchip-signed first-stage bootloader.
t=~0.5sU-Boot
Reads env partition for kernel cmdline + FDT overlays (this is where dr_mode, USB_MODE, and panic=10 live), loads boot.img into RAM, applies overlays, and jumps to the kernel.
t=~3sLinux Kernel 5.10.160
Decompresses, mounts /dev/mmcblk0p7 (rootfs, ext4), starts /sbin/init (busybox). With Phase 1: PANIC_ON_OOPS, HARDLOCKUP, SOFTLOCKUP, ZRAM all active here.
t=~6sinit scripts (rcS)
Busybox init runs S01...S98 alphabetically: udev, networking, dhcpcd, dbus, sshd. Most are stock Buildroot. S98zram sets up the 32 MB compressed swap before cayley services start.
t=~10sS99cayley
The orchestration script we wrote. First action: open /dev/watchdog via cayley-extwd (so any subsequent hang triggers a 30 s reboot). Then DNS lockdown, route metric fixup, SD card mount, HTTPS time sync, tailscaled launch with DERP-only env, finally cayleyd.
t=~30scayleyd starts services
Forks 9 children: go2rtc (camera bridge), cayley-record (15-min MP4 segments), cayley-detect-loop (NPU YOLOv5s), cayley-victron (Bluetooth solar telemetry), cayley-solar-api (HTTP), cayley-net-watchdog (failover + recovery ladder), cayley-snapshot (observability), cayley-cleanup (SD eviction).
t=~75sOnline + serving
Tailscale connects via DERP relay. Funnel cert provisioned. Public HTTPS endpoints respond. Camera RTSP active. Detector running. Heartbeat LED double-blinks. Steady state.

03Six Recovery Layers

Each layer catches what the layer above missed. Click to expand.

6
Hardware watchdog (RV1106 DesignWare)
SoC

If userspace stops petting /dev/watchdog for 30 s → SoC resets itself. Phase 1 added CONFIG_WATCHDOG_NOWAYOUT=y so even close() can't disarm it. Once opened, the dog WILL fire. The deepest safety net.

5
cayley-extwd heartbeat watchdog
Python

Holds /dev/watchdog open. Pets only while /var/run/cayley/heartbeat mtime is fresh (<45 s). If cayleyd hangs → heartbeat goes stale → extwd stops petting → layer 6 fires. Monotonic-clock-aware so NTP jumps don't false-fire.

4
cayley-net-watchdog
shell

Per-iface TCP-probe (not ICMP — T-Mobile drops it). Classifies wlan0/usb0 as noip / apipa / sad / up. Active route arbitration: only real-IP ifaces get default routes. Tailscale magicsock wedge (rx counter stalled) → kill -9 tailscaled. Three kicks in 10 min → sysrq reboot.

3
cayleyd supervisor
Python

Forks 9 children with PR_SET_PDEATHSIG. Exponential backoff (1→30 s) on crash. Restart-rate cap: 10 crashes in 60 s → 60 s penalty. OOM_score_adj=-500 for self + extwd. Crash artifacts (last 4 KB stderr) saved to SD card ringbuffer.

2
Kernel panic / oops handler
kernel

Phase 1 added CONFIG_PANIC_ON_OOPS=y and panic=10. Any kernel oops → panic → auto-reboot in 10 s. Combined with HARDLOCKUP_DETECTOR + SOFTLOCKUP_DETECTOR, even a CPU stuck in a tight kernel loop produces a stack trace and reboot.

1
cayley-snapshot — flight recorder
shell

Doesn't recover anything — but writes boot manifest, 5-min health JSONL, and tail of all cayley logs to SD card. Survives reboots. When something does break, post-mortem is possible. 20-session ringbuffer.

06The Key Code

The few hundred lines that turn a stock Pico Pi into Cayley V3.

S99cayley start sequence (boot orchestration)

# /etc/init.d/S99cayley — first thing: claim the watchdog
case "$1" in
  start)
    mkdir -p /var/run/tailscale /dev/net /var/log/cayley /var/run/cayley

    # cayley-extwd FIRST — claim /dev/watchdog before any other
    # step that could block (DNS, dhcpcd, tailscaled launch).
    if ! pgrep -f "/usr/local/bin/cayley-extwd" >/dev/null; then
      nohup /usr/local/bin/cayley-extwd \
        > /var/log/cayley/cayley-extwd.stdout 2>&1 < /dev/null &
    fi

    # Heartbeat LED — kernel-side trigger if available (Phase 1)
    echo heartbeat > /sys/class/leds/work/trigger 2>/dev/null

    # tailscaled in DERP-only mode (cellular CGNAT defeats direct WG)
    TS_DEBUG_DISABLE_DIRECT=true \
    nohup /userdata/tailscale/tailscaled \
        --statedir=/userdata/tailscale/state \
        --socket=/var/run/tailscale/tailscaled.sock \
        --port=41641 > /var/log/cayley/tailscaled.log 2>&1 &

Hardware watchdog daemon (Python)

# cayley-extwd — owns /dev/watchdog, pets only while heartbeat is fresh
while True:
    age = heartbeat_age()                  # time.time() - mtime
    mono = time.monotonic()
    in_grace = (mono - boot_mono) < GRACE_BOOT
    recent_fresh = (mono - last_fresh_mono) < STALE_AFTER

    if age is None:
        healthy = in_grace                 # pet during boot grace
    elif age < STALE_AFTER:
        healthy = True                     # normal
        last_fresh_mono = mono
    elif recent_fresh:
        healthy = True                     # NTP clock jump cushion
    else:
        healthy = in_grace                 # withhold pet → SoC reset

    if healthy:
        os.write(WDT_FD, b"P")
    time.sleep(PET_INTERVAL)

Network failover (shell)

# cayley-net-watchdog — per-iface TCP probe, route arbitration
classify_iface() {
    iface=$1
    ip=$(iface_ipv4 "$iface")
    [ -z "$ip" ] && echo "noip" && return
    is_apipa "$ip" && echo "apipa" && return
    probe_iface "$iface" && echo "up" && return
    echo "sad"     # has IP but probe fails
}

# When iface degrades from up → not-up while the other is up,
# kick tailscaled so it re-binds to the healthy path.
if [ "$wifi_degraded" -eq 1 ] && [ "$cell_state" = "up" ]; then
    log "iface-failover: kicking tailscaled to rebind"
    kick_tailscaled
fi

07What's Next

Phase 2 — A/B kernel partitions

Two boot.img slots, U-Boot picks active. New kernel installs to inactive slot in trial mode; if it doesn't mark itself healthy in 5 min, U-Boot rolls back automatically. Eliminates "bad OTA bricks the board" forever. Designed in v3/docs/PHASE2-DESIGN.md, ready to implement.

Phase 3 — Read-only rootfs + OverlayFS

Mount / read-only, runtime state in tmpfs/overlay. Power-loss filesystem corruption becomes impossible. Phase 1 already added CONFIG_OVERLAY_FS=y so the kernel is ready.

Hardware additions

LTE aux antenna ($10) — current cellular RSRP is -118 dBm (marginal). Aux gives MIMO downlink diversity, typically +30–80% throughput.
12V smart relay ($15) — remote power cycle for the day the watchdog can't catch something.
